# cs2menus workshop addon

Panorama layouts for cs2menus' `panorama` menu type: `menu.xml` for lists, `grid.xml` for image tiles and `showcase.xml` for one item's editor.
The plugin spawns one `custom_hud_layout` per player and layout, pointing at `panorama/layout/custom_game/cs2menus/<layout>.vxml_c`.
It falls back to HTML menus when `menu.vxml_c` isn't mounted, and to the list when `grid.vxml_c` or `showcase.vxml_c` isn't.

Derived from cs2kz's menu layout ([cs2kz-metamod](https://github.com/KZGlobalTeam/cs2kz-metamod) `workshop/panorama`, by zer0.k).

## Contract with the plugin

Panel ids, dialog variables and classes are written by `src/render/panorama_hud.cpp`. Keep both sides in step:

- Every panel id and dialog variable starts with the layout's prefix, `cm_` in `menu.xml` and `cg_` in `grid.xml`.
  The client matches them by name across all custom HUD layouts, so an unprefixed `item0` would collide with cs2kz's menu.
  After the prefix both layouts share names (`root`, `title`, `close`, `pages`, `nav<N>`, `item<N>`, `val<N>` and the popups), so one writer serves both.
- The client validates custom HUD layouts: only `Panel`, `Label` and `Button`, and a `Label` rejects `html`.
  Text is plain, colors are classes.
- Slot counts: 20 `cm_nav<N>`, 30 `cm_item<N>` with 27 `cm_seg<N>_<S>` runs each, 4 `cm_step_b<N>` and 16 `cm_li<N>`
  (`kNavSlots`, `kItemSlots`, `kRowSegments`, `kStepButtons`, `kListSlots` in `src/render/panorama_hud.h`).
- Grid: 10 `cg_nav<N>` tabs, 24 `cg_item<N>` tiles with `cg_img<N>`, `cg_name<N>` and `cg_val<N>`,
  and the `cg_pager` arrows (`kGridTabs`, `kGridSlots`).
  The tiles sit in `cg_tiles`, which gets `size-m` (4 x 3), `size-l` (3 x 2) or `size-xl` (3 x 1, full height) for bigger tiles.
- `econ.css` has the tile images as `img-<name>` classes: equipment icons like `ak47`,
  skins as `<item>_<paint kit>` (e.g. `weapon_ak47_cu_ak47_asiimov`),
  agents by their `image_inventory` file name, base items like `weapon_knife_karambit` or `ct_gloves`, and a few UI icons (`t_logo`, `ct_logo`, `refresh`, `votescrambleteams`).
  It is generated by `tools/gen_econ_images.py` from the game's pak, so rerun it and republish after an update adds items.
  The game draws SVGs at their own size (mostly 32px), so the script copies each into `images/custom_game/cs2menus` scaled up.
  Stickers go in `econ_stickers.css` as `sticker__<sticker_material with / as __>`,
  loaded by `grid.xml` only (about 11,700 classes).
- `preview` holds a menu's image beside the box, in the popups' place,
  and adds `preview` to the root (`cm_` and `cg_` alike).
  `menu.xml` includes `econ.css` for it, plus `econ_wear.css` with the worn skin renders as `<item>_<paint kit>_medium` and `_heavy`.
- Showcase: 10 `cx_nav<N>` tabs, the menu image in `cx_shot` with the pinned item's `cx_action` button under it,
  18 `cx_item<N>` buttons with `cx_name<N>` and `cx_val<N>`, and the `cx_pager` arrows (`kShowcaseTabs`, `kShowcaseSlots`).
  Tabs and pager reuse `grid.css`, the rest is `showcase.css`.
- The header has `back`, `forward` and `refresh` buttons left of `close` for history navigation.
  Back and forward get `disabled` when unavailable, refresh `hidden`.
  A `collapse` button between refresh and close toggles `collapsed` on the root, which leaves only the header where the box's top edge was.
- The game interns at most 1024 panel ids and dialog variables per layout. `menu.xml` sits near 975, `grid.xml` near 180.
  Budget any new id.
- Value items: rows get `type-toggle` (plus `on`), `type-step` or `type-choice`.
  Editing opens `cm_step` or `cm_list` beside the menu box and adds `shift` to `cm_root` (`cg_` likewise).
- The `cm-col<N>` classes in `menu.css` match `kPalette` in `src/render/panorama_hud.cpp`.
- Font classes in `fonts.css` match `kPanoramaFonts` in `src/cs2menus.cpp`.

## Building and publishing

1. Install the CS2 Workshop Tools and create an addon, e.g. `cs2menus`.
2. Copy `panorama/` into `content/csgo_addons/cs2menus/`.
3. Open the addon in the tools so the layout and styles compile, then publish it to the Workshop.
4. Put the Workshop ID in `cfg/cs2menus/core.cfg` under `Panorama` > `WorkshopId`.
   With [MultiAddonManager](https://github.com/Source2ZE/MultiAddonManager) loaded, cs2menus mounts it on server start.
